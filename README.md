# Художник Валентин Украинец: сайт-галерея

Это новая версия сайта painter.org.ua. Старая PHP/MySQL-CMS переведена на статический генератор **Eleventy**.
Сайт живёт на **GitHub Pages**, а редактировать его можно через веб-админку **Sveltia CMS** по адресу `/admin/`.
Всё бесплатно.

- 3 языка: украинский (основной, в корне сайта), английский (`/en/…`) и немецкий (`/de/…`). Русская версия убрана.
  Структура адресов как на старом сайте: `/about.html`, `/en/article/3.html`, `/de/page-2/`…
- 34 картины (31 опубликована), 2 новости, страница «О художнике», контакты.
- Картинки ужаты: было 115 МБ, стало около 9 МБ.
- Сайт сам пересобирается и публикуется после каждой правки (GitHub Actions).

---

## 1. Публикация на GitHub (один раз, ~10 минут)

1. Зайди на github.com и создай **публичный** репозиторий, например `painter`, без README.
2. Залей в него содержимое этой папки. Проще всего из терминала:

   ```bash
   cd painter
   git init -b main
   git add .
   git commit -m "Сайт художника: первая версия"
   git remote add origin https://github.com/ЛОГИН/painter.git
   git push -u origin main
   ```

   > Через веб-загрузку («Add file → Upload files») тоже можно. Но проверь, что попала скрытая папка `.github`:
   > без неё сайт не будет собираться.

3. В репозитории открой **Settings → Pages**. В поле **Source** выбери **GitHub Actions**.
4. Открой вкладку **Actions**: там запустится «Deploy to GitHub Pages» (если не запустилась, нажми *Run workflow*).
   Через 1–2 минуты сайт будет доступен по адресу:

   **https://ЛОГИН.github.io/painter/**

Название репозитория и адрес сайта прописываются в админку автоматически, вручную ничего менять не нужно.

## 2. Вход в админку

Админка открывается по адресу **https://ЛОГИН.github.io/painter/admin/**. Вход по токену GitHub:

1. На GitHub открой **Settings (профиля) → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token**.
2. Укажи:
   - *Repository access*: **Only select repositories → painter**;
   - *Permissions → Repository permissions → Contents*: **Read and write**;
   - срок действия на свой выбор (например, 1 год).
3. Скопируй токен. В админке нажми **Sign In Using Access Token** и вставь его.

Браузер запомнит вход. Токен никому не передавай: он даёт право менять сайт.
Если художник будет сам добавлять картины, сделай для него отдельный аккаунт GitHub, добавь его в репозиторий как *Collaborator* и выпусти ему собственный токен.

## 3. Что можно редактировать в админке

| Раздел | Что внутри |
|---|---|
| **Картины** | лот, название и размер (UA / EN / DE), описание, цена, большое фото, миниатюра, флажок «Показывать» |
| **Новости** | дата, картинка, заголовок, краткий и полный текст (UA / EN / DE) |
| **Страницы и настройки → О художнике** | текст страницы «Художник» |
| **Страницы и настройки → Контакты и настройки** | телефоны, e-mail, форма связи, подзаголовок в шапке, SEO-тексты |

После нажатия **Save** правка записывается в репозиторий, и через 1–2 минуты она уже на сайте.

**Как добавить картину:**
1. Нажми «Новая картина».
2. Укажи номер лота больше последнего (например, `0350`): от него зависит, что новые работы окажутся сверху.
3. Заполни название на нужных языках и загрузи фото.

Фото автоматически уменьшается до 1600 px и конвертируется в WebP, так что можно загружать прямо с телефона или камеры.
Квадратную миниатюру загружать не обязательно: если её нет, сайт сам аккуратно обрежет большое фото.

## 4. Форма обратной связи (по желанию)

У GitHub Pages нет сервера, поэтому письма отправляет сервис **Formspree** (у него есть бесплатный тариф):

1. Зарегистрируйся на formspree.io на почту, куда должны приходить письма, и создай форму.
2. Скопируй её адрес вида `https://formspree.io/f/xxxxxxx`.
3. В админке открой **Контакты и настройки** и вставь адрес в поле «Адрес формы обратной связи».

Пока поле пустое, на странице «Контакт» показываются только телефоны и e-mail.

## 5. Собственный домен потом

Если позже купишь painter.org.ua (или другой домен):

1. В **Settings → Pages → Custom domain** впиши домен.
2. У регистратора домена добавь DNS-записи:
   - для `www`: CNAME на `ЛОГИН.github.io`;
   - для корня: 4 A-записи GitHub Pages: `185.199.108.153`, `185.199.109.153`, `185.199.110.153`, `185.199.111.153`.
3. Включи **Enforce HTTPS**.

Менять код не нужно: сборка сама поймёт, что сайт теперь в корне домена.

## 6. Локальная разработка

Нужен Node.js 20+.

```bash
npm install
npm start          # http://localhost:8080 с автообновлением
npm run build      # готовый сайт в папке _site
```

## Структура

```
src/
  content/            ← весь контент (YAML), его правит админка
    paintings/*.yml   ← по файлу на картину
    news/*.yml
    about.yml
    settings.yml
  media/              ← фото картин и новостей
  assets/             ← дизайн: style.css, site.js, фон, логотипы
  _data/site.js       ← читает контент и строит страницы на 3 языках
  _data/i18n.js       ← тексты интерфейса (меню, кнопки, подвал)
  _includes/base.njk  ← общий шаблон страницы
  *.njk               ← шаблоны: галерея, художник, новости, контакт, 404
  admin/              ← Sveltia CMS и её настройки
.github/workflows/deploy.yml  ← автосборка и публикация
```

## Что изменилось по сравнению со старым сайтом

- Нет PHP, MySQL, капчи и старого редактора SPAW: ломаться и взламывать больше нечего.
- Пароль от базы и дамп с хэшами паролей в репозиторий **не попали**.
- Вёрстка адаптивная: на телефоне всё читается.
- Увеличение картин работает без Highslide, листается стрелками, клавиатурой и свайпом.
- Убраны Яндекс.Метрика и Яндекс-кнопки «Поделиться».
- Год в подвале обновляется сам; подвал переведён на все 3 языка.
- Русская версия убрана, украинская стала основной.
